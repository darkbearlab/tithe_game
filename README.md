# TITHE

**每十年，教廷抹一名騎士以聖血，送他跨進地獄。**
**他若走到盡頭，人間再安穩十年。他若死了，你為他的兒子命名。**

單一英雄・俯視・動作 roguelite。純 vanilla JS + Canvas 2D，單一 `index.html`，零依賴零資產，開檔即玩。

---

## 這是什麼

| 面向 | 參照 | 取什麼 |
|---|---|---|
| **戰鬥** | DOOM 2016 | push-forward：資源只從敵人身上來，唯一的活路是往前打 |
| **防禦的形狀** | Sekiro | 招架不是為了活下來，是為了累積架勢直到處決——防禦本身就是進攻 |
| **流程** | Hades | 一房一選擇，選的是「你要什麼」不是「你要去哪」 |
| **掉落** | Diablo | 密度。地上一直在發光 |
| **敘事** | — | **血脈紀年**：每個 run 是一代人，父傳子，禱文一代比一代長 |

兩條資源：**聖血**——處決敵人是唯一的回血手段；**怒火**——聽完禱文、想起那個不曾回來的父親，
騎士是滿身怒火跨進地獄的，之後只會被時間磨掉，靠命中、招架與處決補回來，
用來支付格擋、奔跑、技能與大絕招。攻擊本身免費——所以站著不打就是慢性死亡。

跨 run 保留的只有兩樣：**裝備解鎖**（決定它會不會出現在掉落池裡）與**不同的騎士**。
沒有數值升級樹——唯一永遠在增長的是那份紀年，它不給數值，只給意義。

因為沒有那棵樹，難度目標才能固定：**騎士的性能足以打贏全遊戲最難的挑戰，
即使完全沒有解鎖——但在那個難度下，他完全不能犯錯。**
地獄的爪牙也真的強得起這個名號：牠們殺你很快，也死得很快。

而死在地獄裡的騎士不會消失。他的身體被地獄佔據，帶著他死時身上的東西，
在他倒下的那一層等著。**失敗沒有懲罰，失敗是在播種。**

## 和 Homeward 的關係

承襲 [`darkbearlab/Homeward-`](https://github.com/darkbearlab/Homeward-) 的**引擎**
（旋轉攝影機 + pointer-lock 瞄準、揮斬管線、體幹/踉蹌、彈道、打擊感、武器詞條資料模型），
但**不是它的變體**——戰鬥迴圈、流程結構、敘事層全部重寫。

`index.html` 目前仍是 Homeward 的原樣複製（基線 commit），刻意先留著，
好讓「刪到剩引擎」那一刀是一個讀得懂的 diff。

## 開發

改完**一定要跑** headless 驗證（承襲原版守則：逐幀跑遍所有場景的 `update()` + `draw()`，不要只在戰鬥跑）：

```bash
node _check.js              # 全部情境
node _check.js combat       # 只跑名字含 "combat" 的
node _check.js -v           # 失敗時印完整堆疊
```

作法：抽出 `index.html` 的 `<script>`，在 Node `vm` 裡跑，DOM / Canvas / localStorage 全用 stub；
鍵盤滑鼠走**真正的事件處理器**（合成事件），所以輸入分支也涵蓋得到。
每個場景跑固定幀數的 `update()` + `draw()`，任何例外即失敗。地圖是逐張各跑一遍的。

流程：**改 → `node _check.js` 全綠 → 連跑 ×3 穩定 → commit**。

> 和 Homeward 不同，`_check.js` 在這個 repo **有進版控**：
> 這裡要對 `index.html` 做大規模手術，harness 必須跟著程式碼一起走。
